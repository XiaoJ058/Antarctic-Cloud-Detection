# Antarctic-Cloud-Detection

Code and data for AGCNet — cloud segmentation and cloud-type classification in
Antarctic ground-based all-sky imagery from Zhongshan Station, East Antarctica.

> Jiang, Z., Y. Li, W. Deng, L. Liu, X. Liu, X. Zhu, and L. Liu.
> "AGCNet: Solar Position Prior-Guided Progressive Refinement Network for
> Antarctic Ground-Based Cloud Segmentation and Classification."
> *GIScience & Remote Sensing* (under review).
